# 資料の書式

資料（Markdown）に書ける書式の詳細。`html-app` は [html-app.md](html-app.md)。

## 構成と基本

理解のための資料にする。全体像 → 要素ごとの説明 → 必要な分のコード抜粋 → 読むときの注意、の順を基本にする。

- 見出し・表・箇条書き・コードブロックが使える。
- 図は ```` ```mermaid ````（`flowchart` / `sequenceDiagram` 推奨。ラベルは日本語可）。
- 画像は `.rikai/<topic>/assets/` に置き、`![説明](assets/名前.png)` で参照する。外部の画像 URL は表示されない。
- 数式は GitHub と同じ書き方で、KaTeX で描かれる：文中は `$E = mc^2$`（Markdown の記号と衝突するときは `` $`a_1 * b_2`$ ``）、別行は `$$ … $$`（1 行でも、`$$` の行で挟んだ複数行でも）か ```` ```math ````。`$` の直後・直前に空白があるものと、直後が数字の閉じる `$`（`$5 と $10`）は、数式にならない。`\$` は、ふつうの `$`。TeX が読めないときは、理由と元の式が文字で出る。別行の数式は、図と同じく、拡大表示・範囲コメント・版の差分の対象。

## コードブロックの種類

**コードブロックの種類で、形式を選べる**（どれも、読み込みに失敗したら、ふつうのコードブロックになる）：

- ```` ```diff ```` ：差分（`+`・`-`・`@@`・`diff --git` を色分け）。変更の前後を見せるとき。
- ```` ```json ```` ：折りたためる木（深い JSON を、順に開いて読ませる）。JSON として正しいこと（3000 ノード・深さ 40 まで）。**書いたとおりに見える**（数・文字列・キーの順・重複を、変えない）。
- ```` ```terminal ```` （または `ansi`）：端末の出力。ANSI の色（`ESC[31m` など）が使える。ESC は、制御文字のほか、`\x1b`・`\033`・`\e`・`␛` とも書ける。
- ```` ```trace ```` ：手順のタイムライン。1 行に `名前 | 開始ミリ秒 | 長さミリ秒 | メモ（任意）`。`#` で始まる行と空行は無視。
- ```` ```drawio ```` ：draw.io の図（`<mxGraphModel>` の XML）。図形を座標で配置するので、業務フロー・スイムレーン・厳密な配置が要る図向き（Mermaid は自動で配置される。簡単なフロー・シーケンス図は Mermaid でもよい）。返信（`apply` の `body`）でも描かれる。書式は [drawio.md](drawio.md)。
- ```` ```html-app ```` ：書き方は [html-app.md](html-app.md)。安全に関わる要点は、SKILL.md の「守ること」。

## 注意書き（アラート）とタスクリスト

GitHub と同じ書き方で、どちらも**表示だけ**（描画のみ。チェックを押しても、何も保存されない・変わらない）。

### 注意書き

引用の**最初の行に、種類だけ**を書く。5 種類：

```markdown
> [!NOTE]
> 読み飛ばしても困らない補足。

> [!TIP]
> 役に立つコツ。

> [!IMPORTANT]
> 次へ進む前に、知っておくべきこと。

> [!WARNING]
> 戻せない操作・つまずきやすい所。

> [!CAUTION]
> 重大な危険・取り返しのつかない結果。
```

- 題は、種類ごとに自動で付く（メモ・ヒント・重要・警告・注意）。**題は書かない**。種類は、大文字・小文字を問わない。
- **マーカーの行には、ほかの文字を書かない**（`> [!NOTE] 本文` は、ふつうの引用のまま）。知らない種類（`[!INFO]` など）も、ふつうの引用のまま。
- **本文の最上位の引用だけ**が、注意書きになる。リスト・別の引用の中に入れても、ふつうの引用になる（GitHub と同じ）。
- 中には、段落・箇条書き・コードブロック・表・リンク・強調・インラインの `code` を書ける（`>` を行頭に付けて続ける）。
- 使いすぎない（本当に大事なことだけ。続けて並べない）。ユーザーは、中の文を選んで、また、注意書き全体にコメントできる。題の文字は、コメントの引用に入らない。

### タスクリスト

```markdown
- [x] 完了した項目
- [ ] 未完了の項目
  - [ ] 入れ子にもできる
1. [ ] 番号つきでもよい
```

- `- [ ]`（未完了）・`- [x]` か `- [X]`（完了）。`[` `]` の中は、空白 1 つか `x`。`]` のあとに空白が要る。
- 完了の項目は、文字が薄く出る（取り消し線は付かない）。チェック欄は、押せない：**状態を変えるには、資料を直して新しい版を出す**。
- 版の差分では、チェックの変化も「変更」として出る。

## 図・リンク・HTML

- 画像・図で一部を指してもらうときは、`.png` か インラインの `<svg>` で書く（HTML の「モック」は書式を持てない）。
- インラインの `<svg>` は、本文の列より広いと、縦横比を保って自動で縮む（小さい図は、そのままの大きさ）。**`viewBox` を付ける**（`width`・`height` だけなら、`viewBox="0 0 幅 高さ"` を足して扱う）。`<svg>` は、行頭に直接書く（`<div>` などに包むと、縮まない）。
- 別ページへのリンクは `[詳細](page:<page-id>)`。
- HTML は使えるが、`<script>`・`<style>`・iframe などは取り除かれる（動かしたいものは、`html-app` に書く）。
