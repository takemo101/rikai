# ユーザーの画面でできること

ユーザーに、画面の操作を案内するときに読む。資料を書くときの判断（「画像を押すと大きく出ます」と案内してよいか、など）の根拠にもなる。

## 拡大表示・範囲を選んだコメント

- ユーザーは、本文の画像・図（Mermaid・drawio・インラインの `<svg>`）を、**押して、拡大して見られる**（コメントに添付した画像も、同じ拡大表示。添付の画像は、見るだけ。外部画像は対象外）。**`html-app` の枠も、見出しの「拡大表示」から、大きく見られる**。**拡大表示を開いたまま、ユーザーは、範囲を選んで**（画像・図は、元の解像度で切り出される）**コメントでき、`html-app` の枠は、要素を選んでコメントもできる**。

## 並べて比べる

- 版が 2 つ以上あるページでは、ユーザーは、上のバーの「変更の見せ方」（通常｜変更を重ねる｜並べて比べる）の「並べて比べる」で、2 つの版を左右に並べて見られる（`html-app` の枠も、左右とも動く。読み取り専用で、コメントは最新版の本文（「並べて比べる」を閉じた画面）で付ける）。

## Markdown を保存

- ユーザーは、上のバーの「Markdown を保存」で、いま見ているページ・版の本文を、`.md` のファイルとして保存できる（書いた Markdown のまま。コメント・差分の装飾は入らない。画像は `assets/…` の参照のままで、画像のファイルは含まれない。`html-app` の枠は、コードブロックのまま）。
