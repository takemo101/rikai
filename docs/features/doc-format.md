### F9 返信は Markdown

**返信は Markdown**：見出し・表・箇条書き・コード・Mermaid の図・画像が使える。ビューアは、スレッドの中にそのまま描く

### F17 画像は assets のものだけ

**画像は、トピックの `assets/` のものだけ**：資料・返信の `![…](assets/名前)`（または相対パス）は、`assets/` から配信する。外部の画像 URL は表示しない（「外部画像は表示しません」と出す）。`data:image/` は表示する

### F26 コードブロックの種類で形式を書ける

**資料に、コードブロックの種類で、形式を書ける**（sideshow を参考に。JS を動かさないものだけ）：```` ```diff ````（行の種類で色分け：追加・削除・`@@`・ファイルの見出し。`@@` のあと次の `diff ` までは、`---`・`+++` で始まる行も、削除・追加）・```` ```json ````（折りたためる木。根と深さ 1 までは開く。**書かれたとおりに見せる**：数・文字列・キーは、元の文字のまま〔桁あふれする整数・`1.50`・`-0`・`\n` の表記・重複したキー・キーの順を、変えない〕。JSON として読めない・3000 ノード超・深さ 40 超は、ふつうのコードブロック）・```` ```terminal ````／```` ```ansi ````（ANSI の色〔SGR。基本の 16 色・太字・薄字・斜体・下線〕。ESC は、制御文字・`\x1b`・`\x1B`・`\u001b`・`\033`・`\e`・`␛`・`^[` を受ける。色以外の制御文字・シーケンスは捨てる）・```` ```trace ````（`名前 | 開始ms | 長さms | メモ` の行から、ウォーターフォール。最大 200 行。読めない行があればふつうのコードブロック）。**資料の文字は、`app/src/web/doc/render/fmt.ts` で escape して、決まったタグ・クラスの中に入れ、そのあと、これまでと同じ DOMPurify を通す**（`style` 属性は使えないので、trace の棒の位置は、数だけから、無害化のあとに設定する）。AI の返信（Markdown）にも使える（返信の中でも、同じ見た目）。コメントの位置づけは、ブロック（種類のラベル：「差分」「JSON」「端末出力」「トレース」）と、文の選択のまま。形式の各行・各項目は、改行で終わる（引用・AI に届くブロックの文字が、読める形になる）。画面の補助の文字（JSON の個数・trace の軸の目盛り）は、文字にせず、CSS で出す。**コードの色分け（言語別）・JS を動かす `html` は、含まない**（SPEC §7・N3）
