### F25 本文の好きな範囲を選んでコメントできる

> 後続の変更：F47（[小さな UI の直し](ui-cleanup.md#f47-小さな-ui-の直し)）が、この機能の該当の部分を置き換える。

**本文の、好きな範囲を選んで、コメントできる**（利用者の依頼：2026-11-22。「範囲選択は、コンテンツ内なら、どこでも」。最初は、画像・図だけだった）：本文の右下に浮かぶ**「範囲を選ぶ」ボタン**（F32）を押すと、本文の上に選択の枠が重なり、**本文のどこでも、ドラッグで範囲を選べる**（文・表・コード・図・画像・複数のブロックにまたがってもよい。Esc・枠の外を押す・もう一度ボタンを押す・8px 未満の範囲では、やめる。最新版だけ）。選ぶと、新しいコメントの入力欄が開き、**範囲の位置**が対象になり、**範囲の画像（PNG）が、F24 の画像として自動で付く**。**範囲の位置**は、**左上にあるブロック**（その中に画像・図があれば、その最初の画像・図。**壊れた画像**〔読み込みが終わって、大きさがない〕だけは除く。読み込み前の画像は、画像のまま：大きさがないあいだは、枠を出さず、読み込まれたら合わせ直す。**`html-app` のブロックでは、基準は、枠の置き場〔`.appview`〕**：0.24.0 で修正した。それまでは、見出しのツールバーの最初のアイコン〔15px の `svg`〕になっていた：F43 (9)）の大きさに対する比率 `{x,y,w,h}`（左上が原点。4 桁に丸める）。範囲がその基準の外へ出ると、1 を超える・負になる（左上が、その画像・図の外にあっても、基準は、その画像・図のまま）：左上は −100〜100・幅と高さは 1000 まで・0.05% 未満は無効。**範囲の画像**：1 つの画像・図の中に収まるなら、**元の解像度から切り出す**（画像）・図は SVG を画像にして、最大 2 倍で。そうでなければ（文・表・コード・複数のブロック）、**表示されている本文を、見た目を写して複製し、画像にする**（長い辺 2400px まで・白地。番号・枠・選んでいるコメントの枠線・入力中の強調は入らない。`::before` などの疑似要素は写らない。横にスクロールしたコードブロックのスクロールの位置は写らない。壊れた画像は、画像なしで写す）。**`html-app` の枠は、複製の中では、中身が入らない**（別オリジンの隔離した iframe。以前は、背景だけが写り、ダークでは真っ黒な画像になった：0.22.1 で修正）。**そこで、枠は、枠自身に撮らせる**（0.23.0。F42：範囲に枠が重なるとき、枠の中のスクリプトに、自分の見た目を画像にさせ、親が検査して、枠の位置・大きさに描く。印を付ける）。**できないとき**（2 秒のタイムアウト・不合格・枠が消えた・枠が応答しない）は、**画面で見えているとおりの位置・大きさ**（`getBoundingClientRect`。縮小表示〔F40〕の `transform` も含む）**に、「枠の箱」を置く**（0.22.1）：点線の枠・地と区別できる背景・中央に「実行できる枠（画像にできません）」の文字。文字・枠線の色は、画像の地の明るさで決める（ライト `#3f3f46`・ダーク `#e4e4e7`）。箱は、複製の外に置く（祖先の `transform`・`overflow` に左右されない）。枠の祖先が切っている分は、見えている部分だけ。**枠のない範囲は、変わらない**。箱は「枠がある」ことを示すだけで、枠の中は写らない。**範囲に重なるブロック（本文の直下。表・リストなど）の要素の合計（子孫を含む）が 3000 を超える**（巨大な表など。表の 1 行だけを選んでも）と、画像にできず、**理由を、トーストで知らせる**（位置だけで、コメントできる）。そのほか、画像にできなかったとき（ブラウザによっては、できない）も、トーストで知らせ、位置だけで、コメントできる。本文に、**範囲の枠**を出す（マウスを置くとカードと光る。入力中はオレンジ。本文の領域の左右の外へ出る分は、収める）。番号は、F22 の同じ丸（範囲の上端の高さ）。AI に届くもの：`anchor.region`（比率）・`anchor.label`（画像・図の中に収まる範囲は「画像: …の一部」・それ以外は「範囲：…（基準のブロックの頭。図は「図」）」。枠の画像が入るときは「（枠の画像は、枠自身が作ったもの）」を足す。**個別表示で選んだ `html-app` の範囲は、「（枠の幅 980px で選択）」のように、選んだときの個別表示の枠の幅を足す**：長さ 120 以内）・`images`（範囲の画像のファイル）。コメントの位置づけは、ブロックの探し方（F12）のまま（ブロックが見つかれば、範囲は、同じ比率で付く）。**比率は、基準の 1 つのブロックの大きさに対するもの**なので、窓の幅・折り返しが変わると、文や複数のブロックにまたがる範囲の枠は、選んだ内容から、ずれることがある（**範囲の画像が、正確な内容**）。**個別表示（F43）でも、同じ形の錨で、範囲を選べる**（画像・図は、拡大した状態の座標から、元の解像度で切り出す）。**HTML の見た目の取り込み（スクリプトを動かすもの）は、含まない**（§7）。**既知の制約**（0.22.1）：枠の箱が小さい（高さが数十 px 未満）と、文字が切れる・サムネイル（128px）では、箱の文字が粗く見える。**0.24.0 より前に保存された `html-app` の範囲コメントは、位置がずれる**（基準の修正のため：F43 の既知の制約。許容）。**古い基準の範囲が、大きくはみ出して、本文の高さを伸ばさないように、描画だけ、クランプする**（`clampRegionRect`〔`overlay/layout.ts`〕：`html-app` のブロックの範囲の枠だけ、描画用の比率を、基準の箱の周り `[-1, 2]` に収める。空なら描かない。本文と個別表示の両方。**保存データは書き換えない**・位置は、ずれたまま・画像・図・文の範囲には使わない）

### F31 範囲の枠の調整と添付画像の拡大

> 後続の変更：F49（[拡大表示の統一と上のバーの切り替え](ui-cleanup.md#f49-拡大表示の統一と上のバーの切り替え)）の (2)が、この機能の該当の部分を置き換える。

**範囲の枠を、あとから調整できる。添付の画像を、大きく見られる**（利用者の選択：2026-11-22。「枠の位置・大きさの微調整」「サムネイルを大きく」）：

- (1) 範囲を選んだあと、入力欄を開いている間、本文の**オレンジの枠は、ドラッグで動かし、角（4）・辺（4）で大きさを変えられる**（本文の外へは出ない。最小 12px）。**離すと、その範囲で、対象・見出し・切り出しの画像を、作り直す**（前の範囲の画像は外し、新しい画像を付ける。書きかけの文字・ユーザー自身が付けた画像は、残る）。ドラッグしている間は、枠を描き直さない。入力中でない枠（付いたコメントの枠）は、これまでどおり、押せない。
- (2) 入力欄・カードの**添付の画像は、押すと、拡大表示で開く**（別のタブは開かない。0.29.0 で変更：以前は、画面の中の簡易の表示で、Esc・押すと閉じた。いまは、本文の画像と同じ拡大表示のステージ〔ズームイン／ズームアウト・全体に合わせる・100%・ホイール・ドラッグ〕で、**見るだけ**〔ドックなし〕。Esc・「×」・背景で閉じる。**画像そのものを押しても、閉じない**：F49）。入力欄のサムネイルは、少し大きくする（高さ 72px）。**本文の画像・図の拡大は、F37**

### F32 範囲を選ぶボタンは右下に浮かぶ

**範囲を選ぶボタンは、本文の右下に浮かぶ**（利用者の指摘：2026-11-22。「都度『コメント』と一緒に『範囲選択』も出るので、範囲選択は、フローティングの UI にした方が」。F27 の「入口は、1 つのバー（コメント・範囲）」を、変更）：

- (1) 入口のバーは、**「コメント」だけ**（文を選んだとき・ブロックにマウスを置いたとき）。
- (2) 本文の領域の**右下に、「範囲を選ぶ」の丸いボタン**が、いつも浮かぶ（スクロールしても、同じ場所。最新版を開いているときだけ）。押すと、F25 の範囲を選ぶ状態になり、ボタンは「やめる」（色つき）に変わる。もう一度押す・Esc・枠の外を押すと、やめる。ボタンを押しても、文の選択は外れない

### F56 範囲の枠を隠せる

**範囲の枠を、1 つのボタンで隠せる。あわせて、html-app の見出しの注意文を、見える文字から外した**（利用者の依頼：2026-11-25。(A)「html-app の場合、コメント枠がついていると、そもそもクリックなどの操作の邪魔になることがあるので、これ非表示にするモードがあってもいいですね」(B)「この表示は必要ないです」〔html-app の枠の見出しの上の「実行できる枠 1（隔離されています。パスワードなどの秘密は、入力しないでください）」〕）。0.1.6。設計の判断は [ADR-0060](../decisions/0060-hide-region-boxes.md)。

- (1) **不具合の測定**（実 Chrome。範囲コメント 3 つが重なる枠で）：本文の保存済み `.regionbox` は、枠の中の操作が届く。**本文の入力中の枠 `.regionbox.pending` は、全部届かない**（F31 の調整のハンドルのため `pointer-events: auto`）。**拡大表示の保存済み `.fv-box` は、全部届かない**（クリックでスレッドを選ぶため）：**重なる位置の操作が、すべて枠に吸われる**。拡大表示の入力中の枠は届く。番号の丸・関連の線は、問題なし。
- (2) **(A) 隠すモード**：状態 `ui.regionBoxes`（既定は出す・`ui.links` と同じく `rikai-ui` に保存し、リロード後も維持）。**対象は、本文の `.regionbox` と拡大表示の `.fv-box`：画像・図・文・`html-app` のすべての範囲の枠**（一括：一部だけ隠すと、枠が混在して、分かりにくいため）。要素コメントは枠を持たないので、対象外。**DOM に置かない**（本文は `place.ts`・拡大表示は `useFocusCtx` の `regions` で絞る）。関連の線（F35・F55）は、端点の枠がないので、消える。**番号の丸・カードは、そのまま**（丸の高さも同じ）。
- (3) **ボタン**：右パネルの見出し（`#regions-toggle`。「関連の線」の隣・`.panel-h-tools`）と、拡大表示のドックの見出し（`.fv-regions-toggle`・`.fv-dock-tools`）。`panel/RegionBoxesToggle.tsx`。目のアイコン（Eye／EyeOff）・名前は `aria-label="範囲の枠を隠す"` で固定・`aria-pressed`＝隠している・`title` にいまの状態。**上のバーの見出し `.cap` には足さない**（すでにボタンが多く、狭い窓で崩れやすい）。狭い窓（1100・820・640px）でも、窓内に収まり、見出しは 1 行のまま。
- (4) **入力中の枠は、隠している間も、押せない破線で残す**（`.regionbox.pending.still`・ハンドルなし）：枠を隠したまま範囲を選ぶと、何を選んだか分からないため。枠の中の操作は塞がない。**隠している間は、入力中の枠の調整（F31）はできない**（枠を出してから調整する）。終了したトピック（F54）でも、同じボタンが効く。
- (5) **(B) 見出しの注意文**：html-app の見出し（`.cap`）の**文字を、空にした**（`markdown.ts`）。**安全の注意（N3：「隔離されています。パスワードなどの秘密は、入力しないでください」）は、見出しの行の `role="group"`・`aria-label`・`title` として付ける**（`apps.ts`。読み上げとホバーで、失わない）。比べる画面（F44）は、見出しに道具がないので、iframe の `title` に持たせる。拡大表示は、元から注意文がない。名前・注意文は、`htmlapp/appName.ts` の 1 か所。
- (6) **範囲の名前（`textOfBlock`）**：html-app は、`実行できる枠 N` を返す（見出しの文字に頼らない）。**既存のコメントの旧い名前**（`範囲：実行できる枠 2（隔離されています。…`）：**保存データは変えない**・表示だけ、`quoteOf` が注意の部分を除く（`stripAppNotice`）。**AI に届く名前は、旧いコメントでは、旧いまま**。`blockText`・`plainText`・ハッシュ・`textIndex`・`blockLabel` は、見出しの文字を見ていない（位置づけは変わらない）。
- (7) **既知の点**：**表示中の拡大表示でも、`.fv-box` は、枠の中の操作を塞ぐ**（「隠す」で回避する設計。表示中の動作は、変えていない。要望があれば、枠を押せなくして、番号の札だけ押せるようにする案）・表示中の本文の入力中の枠も、同様に塞ぐ・**実際のマウス・他のブラウザ・スクリーンリーダーは、未確認**。
