# ADR-0013 外観のモード（ライト・ダーク・システム）の方式

- 日付：2026-11-23
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F36](../features/appearance.md#f36-外観のモードを選べる)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-23「ライトモードとダークモードとシステム自動モードみたい…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。上の依頼の範囲。0.17.0）**外観のモード**（F36）：**方式は、CSS の `color-scheme` と `light-dark()`**（ハードコードの色を、`app.css` の `:root` のトークンに集め、1 か所で、ライトとダークの値を持つ。OS の外観の変化には、CSS だけで追従する）。**既定は system**。**切り替えは、上のバーの、アイコン 1 つのボタン**（system → light → dark の巡り）。**ちらつき（FOUC）は、`theme-init.js`（同期・外部ファイル）を、`<head>` の CSS より前に置いて、避ける**（CSP が `script-src 'self'` で、インラインのスクリプトは、使えないが、外部ファイルは許される。`main.tsx` の `applyTheme` も、残す）。**Mermaid** は、ライト `neutral`・ダーク `dark`（`securityLevel: 'strict'`・無害化は、変えない。ダークのときだけ `themeVariables`。図のキャッシュのキーに外観を含め、描画は 1 本の連鎖で、描き終えた時点で外観が違えば、捨てる）。**`html-app` の枠は、変えない**（`color-scheme: light`。AI が書いた別の文書で、白のまま：中身の色は、AI が決める）。**範囲選択の画像の地の色は、画面の紙の色**にした（ダークでは、暗い地・明るい文字の画像が、AI に届く）。**ダークの配色**：背景 `#09090b`・面 `#111113`・カード `#18181b`・罫線 `#27272a`（入力欄の罫線は `#52525b`）・文字 `#fafafa`・補助 `#a1a1aa`・アクセント `#60a5fa`・リンク `#93c5fd`（ライトの値は、F36）。**依存は、増やしていない**。**F1〜F35 の振る舞い・HTTP・データの形式・安全（N1〜N3）は、変えない**（`rikai-ui` に `theme` が足された。古い値は、そのまま読める）。**ライトで、0.16.1 と違う点が、3 つ（意図した違い）**：JSON の文字列の色 `#1a7f3c` → `#167435`（強調の上で、5.02:1）／**無効の主ボタン**：薄めた青に白文字（1.97:1）→ **灰色の面に灰色の文字**（ライト約 3.8:1・ダーク約 4.6:1。**ライトでも、無効の Submit は、薄い青から、灰色になる**）／**placeholder の不透明度 0.85 → 1**（コントラスト 4.24 → 5.1:1。少し濃くなった。2 回目のレビューで、申告になかった変化として見つかった）。画素比較（0.16.1 とライト。最初の 2 つ）：674×487 のうち 130 画素・最大差 11/255・JSON の文字列 2 か所だけ。**端末の枠の中の強調**：琥珀の上書きは、未解決だけ。解決済みは、背景なし・淡い灰色の下線（0.16.1 では、解決済みの文字が、暗い地に暗い文字で、見えなかった）。**既知の制約**：`--line-strong` は、ダークで、カードに対して約 2.0:1・古いブラウザのフォールバックなし（Chrome 123+・Safari 17.5+・Firefox 120+）・Tern の外観が OS に従うかは、未確認（[検証記録](../verification.md)）
