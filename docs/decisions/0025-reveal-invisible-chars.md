# ADR-0025 枠から来た見えない文字は、見える形にした

- 日付：2026-11-23
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F42](../features/html-app.md#f42-html-app-の枠から下書きのコメントを作れる)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-23「進めて（利用者の決定。html-app-review…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。F42 の独立レビューの指摘への対応）**枠から来た、利用者に見えない文字は、取り除かず、見える形にした**（`reveal`：`\uXXXX`）：取り除くと、利用者が気づけない（画面に描かれないタグ文字〔U+E0000 台〕や方向制御が、コメントに入るのを、**見えるようにして、利用者が判断できる**ようにする）。**見出しと錨のラベルに、枠が決めた文字を入れない**（`selector`・`text` は、JSON のブロックの中だけ）：枠が、偽の区切り・利用者の追記に見せかけた文を、地の文として並べられるため。**見出しは固定の形で、「枠の自己申告」と書く**（要素の情報は、利用者が押した要素とは限らない：別オリジンの枠の中のクリックは外から見えないので、防げない）。**「枠から」の札は、錨の形で判定する**（`fromFrameAnchor`）：ラベルだけだと、利用者が「枠から」で始まる本文の文を選んだときに付きうる。**選択モードでクリックを止める強化は、仕様としては保証しない**（敵意のある枠のコードは、`Event.prototype` を置き換えられる。影響は枠の中だけ。橋が本物を退避して使う、軽い強化だけ入れた）（[検証記録](../verification.md)）
