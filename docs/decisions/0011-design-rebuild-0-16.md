- 関連の機能：[F22](../features/appearance.md#f22-コメントと本文の位置が分かる)・[F23](../features/appearance.md#f23-画面の広さを変えられる)・[F33](../features/appearance.md#f33-落ち着いた見た目と過去のコメントの整理)・[F35](../features/appearance.md#f35-コメントと本文の対象を線で結ぶ)

（AI の判断。上の 2 つの依頼の範囲。0.16.0）**画面のデザインを作り直した**：ニュートラルな灰色＋アクセント 1 色の青（`#2563eb` 系）・角丸 4／6／8px・影はほぼなし・本文は、カードをやめて、15px・行間 1.8・最大幅 760px・アイコン（`lucide-react`。使うものだけがバンドルされる。ISC のライセンスは、`THIRD-PARTY-LICENSES.txt` に、自動で出る）・編集／削除／画像は、アイコンだけ（`aria-label` と `title` つき）・コメントの強調の語は、オレンジから、青の破線に（入力中）・「画像を付ける」は、「返信を追加」と同じ行・「AI」の発言者のアイコンは、やめた（札と重複）・右パネルのタブの文字は、コントラスト 4.5:1 以上。**CSS は、`legacy.css` から、`app.css`（改名）と `connectors.css` に**（上の 2026-11-23 の行の「見た目は `legacy.css` のまま」は、この行で変わった）。**F35（関連の線）を足した**。**独立レビュー 1 回の結果、F35 の仕様を変えた**：縁に寄せた線は、選んでいる・光らせている・入力中のものだけ／それ以外は、両端が見える範囲の中にあるときだけ／トグルは、`#docbar` から、右パネルの見出しへ移した（`#docbar` が折り返すと、2 行目に落ちたため）。**依存を 1 つ足した**：`lucide-react`（`app/package.json` の `devDependencies`。ビルドで同梱する。SPEC N5 の方針のとおり、利用者に `npm install` は要らない）。**F1〜F34 の振る舞い・HTTP・データの形式・安全（N1〜N3）は、変えない**。マークアップは、意図して変えた（アイコンだけのボタンは `aria-label` で探す・「→」「›」「☰」「←」はアイコン）：**アクセシブルな名前が変わった 2 件（意図した違い）**：「← すべてのコメントに戻る」→「すべてのコメントに戻る」・ページへのカードのリンクの末尾の「→」がなくなった（名前としては、良くなった）。それに合わせて、テストを直した（[検証記録](../verification.md)）
