# ADR-0018 「あなたの番」の条件

- 日付：2026-11-23
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F39](../features/turn-notify.md#f39-いま誰の番かが一目で分かる)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-23「submit 待ち状態か？どれに対して Submit…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。レビュー 1 回目の指摘への対応。F39）**「あなたの番」は、AI の新着返信か未回答の質問があるときだけにし、未解決だけのときは、灰色の中立な「未解決 n」にした**（やることが残っているだけで、利用者に番が回ってきたわけではないため）。見える数字は、スレッドの数（1 つの返信に質問が付いていても 1）。読み上げは、件数を含まない状態名だけ。左の一覧の印は、アイコンだけ（「待ち」は、既存の試験のため文字つきのまま）。幅が足りないときは、進み具合のチップとヒントを先に縮め、`#turn` は縮めない。**直さずに、制約として残した**：ほかのトピックの印は、一覧の API が未送信の数を返さないため、開くと変わることがある（将来は `/api/topics` に `unsent` を足す）／Submit 済みの間は、「AIの返信待ち」だけを出す（設計どおり）
