# ADR-0049 整理フェーズ ④c：フォルダ化

- 日付：2026-11-24
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F44](../features/versions.md#f44-版を並べて比べる)・[F43](../features/zoom.md#f43-個別表示でコメントする)・[F28](../features/html-app.md#f28-資料に実行できる枠-html-app-を書ける)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-24「整理フェーズ ③b の、利用者の決定（動く見本で、1…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。整理フェーズ ④c。RIK-061）**移動だけにした**：ファイル名・本体は、変えない。**フォルダ化は、まとまった 3 つの塊（`compare/`・`focus/`・`htmlapp/`）だけ**：ほかの部品（`doc`・`panel`・`interact`・`layout`・`lib`・`store`）は、層のままにした（全面の組み替えは、動いている部品の import を大量に変え、差分の読みにくさに見合う利点が小さいため）。**`lib/compare.ts` と `lib/frameWidth.ts` は、`lib/` に残した**：ストア（`store/slices/compare.ts` ほか）が使っており、**ストアが機能フォルダを import しない**（④a の「ストアは上の層を import しない」を守る）ため。**CSS は、`app.css` の 3 節を、各フォルダの CSS に切り出した**：切り出すと、ルールの順序が変わる（`index.css` は、バイト単位では同一にならない：大きさ・ルール数は同じで、順序だけが違う）。**見た目が変わらないと判断した根拠**：競合しうる組（同じ要素・同じ特異性・同じプロパティ）を機械的に調べて、実際に挙がった組は、別の部品の要素で、同じ要素には当たらなかった・実際の Chrome で、新旧を 14 状態で比べて、全要素の computed style が一致した。**e2e は、1 回だけにした**（移動だけで、3 回連続の全件成功は、変更の大きさに見合わないため）：**3 回連続の全件成功とは書かない**。**独立レビューも、受けない**（移動だけ。import の書き換えは、型検査・Vitest・e2e が見る。依存の向きは、import の解析で確かめた）。**フォルダ単位の推移的な循環は、直さない**（もとの `doc`・`panel`・`interact` 間の結び付きによるもので、今回の範囲外。ファイル単位では 0 件）。`biome.json` に `"!src/web/*/*.css"` を足した（`styles/` は、元から対象外。新しい CSS を、検査・整形の対象にしないため）。詳細：[docs/verification.md](../verification.md)
