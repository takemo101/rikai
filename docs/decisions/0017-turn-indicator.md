# ADR-0017 「いま、誰の番か」の表示

- 日付：2026-11-23
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F39](../features/turn-notify.md#f39-いま誰の番かが一目で分かる)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-23「submit 待ち状態か？どれに対して Submit…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。上の依頼の範囲。0.20.0）**「いま、誰の番か」の表示**（F39）：**判定は、`lib/turn.ts` の 1 か所の純粋関数**にして、上のバー・左の一覧・カード・タブのタイトルが、同じ判定を使う。**優先順位**：終了 → 未送信 → AIの返信待ち → 印なし（スレッド 0）→ あなたの番 → すべて解決（未送信が、待ちより先：Submit 済みで、新しいコメントを付けたとき、まず「Submit」を促すため。前回分の待ちは、小さな札で残す）。**解決済みスレッドの返信と質問・答えないまま会話が進んだ質問〔stale〕は、数えない**（やることではないため）。**サーバー・CLI・HTTP・データの形式は、変えない**（画面が持つデータだけ）。**AI が `poll` で待っているかは、サーバーから分からないので、使わない・出さない**。読み上げは「状態：あなたの番」だけにした（内訳の件数が変わるたびに、読み上げ直さないため）。**他のトピックは、要約だけで判定**（未送信と内訳は出さない）（[検証記録](../verification.md)）
