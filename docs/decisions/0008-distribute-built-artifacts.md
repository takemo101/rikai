# ADR-0008 成果物を skills/rikai/ にコミットして配る

- 日付：2026-11-22
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-22「仕様が固まったので、サーバーは Hono、フロントは…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。上の判断の範囲）**配布**：ビルド済みの成果物（バンドルした `rikai.js`・`public/`）を、`skills/rikai/` にコミットする。理由：プラグインは、リポジトリの clone を入れるだけで、ビルドの手順がなく、`install.sh`・各エージェントの導入が、そのまま使える。開発用のソースは `src/`（`server`・`cli`・`web`・`shared`）。成果物が古くなっていないことは、テストで確かめる。**画面の更新を SSE にする**（§5 の「サーバー側から押し出さない」を変える）のは、動作が揃ったあとの、別の PR。**Node の下限は 20**（18 は終了している。`install.sh` の確認も、切り替えのときに直す）
