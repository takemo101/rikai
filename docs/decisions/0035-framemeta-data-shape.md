# ADR-0035 データの形の拡張（frameMeta）

- 日付：2026-11-24
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F45](../features/html-app.md#f45-枠から取った情報を情報の行にする)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-24「メタデータとして、コメントじゃなくて、UI 上に『要…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。上の依頼の範囲。0.26.0）**データの形を拡張した**（コメントのメッセージに、省略できる `frameMeta`）：**利用者の依頼のため**。これまで、「データの形は変えない」（F42・F43・F44）としていたのは、AI の方針で、利用者の依頼ではなかった。**コメントの本文に、機械的な文章を書き込まない**という依頼は、本文とは別の持ち場がなければ、満たせない（本文以外に、枠の情報を持つ場所が、データにない）。**利用者に伝えて、進める了承を得た**。`.rikai/` の `schema` は、上げない（省略できる項目の追加：古いデータは、そのまま読める）。**`poll` の出力にも、`text` とは別の項目で出す**：AI が、利用者の言葉と、枠の自己申告を、取り違えないため（SKILL.md）。入力の形（`apply` の JSON）・コマンドは、変えない（[検証記録](../verification.md)）
