# ADR-0027 個別表示にした

- 日付：2026-11-23
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F37](../features/zoom.md#f37-本文の画像と図を拡大表示できる)・[F43](../features/zoom.md#f43-個別表示でコメントする)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-23「拡大表示を開いたままでコメント入力したい。画像や図形…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。上の依頼の範囲。0.24.0）**個別表示にした**（F43）：**F37 の拡大表示を、個別表示に拡張した**（開いたまま、コメントを入力できる：ドックに、既存の `Composer` を置き、`composer` の状態を共有する：閉じても、下書きは、パネルに残る）。**`html-app` の枠は、本文の枠を移さず、新しい iframe を作る**（移すと、再読み込みで状態が消え、本文の枠が壊れるため。隔離〔`sandbox="allow-scripts"`・`APP_CSP`・src〕は、同じ）。**錨は、F25 と同じ形**（データの形・API・`apply`／`poll` の入力は、変えない）。**`html-app` の範囲の基準を、枠の置き場（`.appview`）に直した**（F25 の不具合：見出しのツールバーの最初のアイコン〔15px〕が基準になっていた）。**0.24.0 より前の `html-app` の範囲コメントは、位置がずれるが、許容した**（`.rikai/` は書き換えない・古い基準を確実に見分ける方法がない・影響は、0.22.1〜0.23.0 の、作者の試用分だけ〔推測〕）。**枠の中の Esc を、橋が `esc` で親へ転送する**（枠の中にフォーカスがあると、Esc は枠が受けて、親に届かず、個別表示を閉じられないため）：150ms に 1 回まで・Escape だけ・個別表示の枠だけが処理・選択モードの Esc は、既存の `pick-cancel` だけ（二重にしない）。**Esc の順序は、`lib/escape.ts` の 1 か所**（範囲選択 → ドラッグ中 → 道具の中止 → 閉じる）。**F42 の再レビューの修正**：**絵文字の直後の U+FE0E／FE0F 1 個だけは、見える化しない**（`❤️` が割れないように。それ以外は、見える化する：異体字セレクタでの隠し文字を防ぐ）。ZWJ 絵文字は、この時点では割れたが、**独立レビューの指摘で、例外を入れた**（下の行）（[検証記録](../verification.md)）
