# ADR-0029 reveal の例外（キーキャップ・絵文字の間の ZWJ）

- 日付：2026-11-24
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）

- 決定の元：[利用者の決定](user-decisions.md)（2026-11-23「一旦全ての依頼の実装を全て進めてほしい。明日朝あたり…」）。文中の「上の…」は、この決定を指す。

（AI の判断。F43 の再レビュー〔`main` 0.24.0〕の指摘への対応）**`reveal` の例外（キーキャップ・絵文字の間の ZWJ）で運べる情報量は、許容と判断した**：絵文字 1 つあたり最大 2 ビット程度（状態の 1 本の文字列〔1000 文字〕で約 62 バイト・8KB 全体で数百バイト・`text`〔80 文字〕で約 5 バイト）。運ぶには、目に見える絵文字が数百個並ぶ必要があり、読む側も、符号の決まりを知っている必要がある。**例外のふるまいの不揃いも、許容した**（`❤` ＋ FE0F はそのまま・連結していない `😀` ＋ FE0F は、FE0F が見える形になる：正当な絵文字が、まれに崩れる程度）。**`clampRegionRect` を画像・図にも当てる改変が、試験で落ちなかった → 単体を足して、落ちるようにした**。**F43 の SPEC の訂正**：「枠の幅の既定を揃える」は、**設定**を揃える意味で、px ではない（上の行）
