# ADR-0026 通知の icon を PNG の data: にした

- 日付：2026-11-23
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F41](../features/turn-notify.md#f41-確認すべきイベントをブラウザの通知で知らせる)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-23「通知時にアイコン画像も表示してほしい（利用者の依頼。…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。上の依頼の範囲。0.23.1）**通知の `icon` を、rikai の PNG の `data:` にした**（F41）：**SVG は、通知のアイコンとして使えないブラウザが多い**ので、`favicon.svg` を 192px で描いた PNG にした。**`data:` にした理由**：外のものを読まない（N1）・サーバーの変更や、通信を増やさないため（`/favicon.svg` や外部 URL の画像を指さない）。**`favicon.svg` との一致は、SHA-256 の検査で守る**（`NOTIFY_ICON_SOURCE_SHA256`：favicon を変えると、単体テストが落ちて、アイコンの作り直しを促す）。**`badge`・`data` は付けない**（変わらない）。サーバー・CLI・HTTP・データの形式は、変えない（[検証記録](../verification.md)）
