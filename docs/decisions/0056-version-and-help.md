# ADR-0056 バージョン表示と `--help`：版はビルド時に埋め込み、ヘルプは 1 か所のデータから描く

- 日付：2026-11-24
- 種別：AI の設計の判断（0.1.2）
- 関連の機能：[F53](../features/ai-commands.md#f53-バージョンとヘルプを見られる)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-24「web 画面と CLI でのバージョン表示」「CLI の --help の表示（見やすく・分かりやすく）」）。版の採番は、同じ日の「版番号を 0.1.1 に振り直す」の行。
- 一覧：[ADR の一覧](README.md)

## 決めたこと

### 版の正本と、ビルド時の埋め込み

- **版の正本は、`package.json` の `version`**（`plugin.json` との一致は、`plugin.test.ts` が検査する）。
- **ビルド時に埋め込む**：esbuild・Vite・Vitest の `define` で `__RIKAI_VERSION__` を置く（`app/scripts/version.ts` が `package.json` を読んで定義を作る。`app/src/shared/version.ts` が `VERSION` として export する）。**実行時に、ファイルを読まない**。理由：`rikai.js` を 1 ファイルだけ別の場所へ置いても、同じ版を出す。画面とサーバーが、別々に版を読んで食い違うことがない。
- 採らなかった案：実行時に `package.json` を読む（配布物にない・場所が分からない）。サーバーの API に版を足す（画面の版と CLI の版が、別の経路になる。外への通信も増やさない方針）。

### CLI

- `rikai --version`・`-v`・`version` は `rikai 0.1.2` を出して、終了コード 0。
- `-h`・`-v`・`--help`・`--version` は、**値を取らないフラグ**。`--title -v` のように値として渡されたら、そのまま値。
- `--force` は、誰も読んでいなかったので、`parseArgs` から外した。
- **ヘルプ・バージョン・未知のコマンドは、`createStore` より前に答えて終わる**（空のディレクトリで実行しても、`.rikai/` はできない）。
- **未知のコマンドは、`--help` を付けても、`help xxx` でも、エラー**（stderr・終了コード 1・stdout は空）。理由：打ち間違いを、成功（終了コード 0）に見せない。エージェントが、コマンド名の誤りを検出できる。`rikai --help`・`-h`・`help`・引数なしは、ヘルプ（stdout・終了コード 0）。`rikai <コマンド> --help` は、そのコマンドの使い方・オプション・入力・出力・例。

### ヘルプのデータ化と色

- **内容は、`app/src/cli/help.ts` の定数 1 か所**（全体のヘルプと、各コマンドのヘルプを、同じデータから描く）。構成：説明 → 使い方 → コマンド（「資料を作って見る」new／open／status／stop・「AI がコメントを受けて返す」poll／pull／apply）→ オプション → 例 → 詳しい説明への案内 → 内部用 `serve`。画面の言葉は「AI に送る」（旧 Submit を直した）。
- **ドリフト防止**：`cli.test.ts` が、`help.ts` のコマンド一覧と `main.ts` の `case`、コードが読む `flags` とヘルプのオプション一覧の一致を検査する。
- **色（ANSI）は、出力先が TTY で、`NO_COLOR` が空でないときだけ**（パイプ・`NO_COLOR` では 0 個。未知のコマンドのエラーは、stderr の TTY で判断）。エージェントが読むパイプの出力に、制御文字を混ぜない。

### 画面の置き場所

- **左の一覧の下端に、小さく `v0.1.2`**（`title` は「rikai v0.1.2」）。上のバーのロゴの `title` も同じ。終了画面は、左下に別に出す。空の画面は、一覧に出る。
- **上のバーには置かなかった**：420px で余裕がなく、`#top` の高さ 44px を保つため。`#docbar` は触っていない。
- 1100px 以下で一覧が自動で隠れても、☰ のドロワーで見える。900px 以下は、ロゴが非表示なので、ロゴの `title` は使えない（一覧の版が、唯一の表示）。

### 外への通信

- **増やさない**（更新確認などは、しない）。`apply`・`poll`・`pull`・`status`・`open`・`new` の JSON は、変えていない。

## 残る課題

- 旧い記述の整理（`HELP` を `help.ts` に・`rikai submit` という、実在しないコマンドへの言及の訂正）は、この変更と同じ日に、文書側で直した（履歴の記録は、そのまま）。
