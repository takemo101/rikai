# ADR-0004 rikai.js を責務ごとに lib へ分ける

- 日付：2026-11-21
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-21「進められるものは、タスクに分けて、PR ごとに me…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。上の委任の範囲）`rikai.js` は、責務ごとに `lib/`（util・store・ask・actions・agent・server）へ分け、入口だけを残す。動作は変えない。ブラウザの `app.js` は、ビルドなし・自動テストなし・読み込み順の決めが要るので、分けない（負債として記録）
