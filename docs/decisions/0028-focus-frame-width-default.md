# ADR-0028 個別表示の枠の幅の既定を、本文に揃えた

- 日付：2026-11-23
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F43](../features/zoom.md#f43-個別表示でコメントする)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-23「拡大表示を開いたままでコメント入力したい。画像や図形…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。F43 の独立レビューの指摘への対応）**個別表示の `html-app` の枠の幅の設定の既定を、本文の枠が、いま選んでいる設定に揃えた**：個別表示の枠（980px で 2 列）と、本文の枠（634px で 1 列）で、同じ範囲が別の要素を指すため。**揃うのは設定（自動・375・768・1280・1920）で、px ではない**（2026-11-24 に、再レビューの指摘で、記述を訂正：「自動」のとき、本文の枠は本文の幅・個別表示の枠はステージの幅で、px が違い、`@media` が違いうる）。**px が違うときは、範囲の錨のラベルに、選んだときの枠の幅を書き**、**ステージの道具の帯に、琥珀色で知らせる**（防げないので、利用者と AI に伝える）。**古い基準の範囲は、保存データを書き換えず、描画だけクランプした**（`clampRegionRect`：基準の箱の周り `[-1, 2]`。古い基準を確実に見分ける方法がなく、`.rikai/` を書き換えないため。位置は、ずれたまま）。**日本語の変換中の Esc・Enter は、処理しない**（変換の確定・取り消しで、個別表示が閉じる・送信されるのを防ぐ）。**`reveal` に、正当な絵文字の例外を入れた**：キーキャップ・**絵文字の間の ZWJ 1 個**〔20 個まで繋げる〕。**「ZWJ 絵文字は割れる：安全側」としていた判断を、訂正した**（家族・国旗・職業の絵文字などが、見える形に崩れて、使いにくいため）。**悪用を小さくするため、上限と条件を付けた**：文字の間・絵文字と文字の間・連続する ZWJ・間に別の見えない文字が挟まる・21 個目以降は、見える化する（ZWJ に隠した文字列は、残らない）。ブロックそのものが `<img>` の画像も、個別表示で開けるようにした（F37 からの後退の修正）（[検証記録](../verification.md)）
