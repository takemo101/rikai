# ADR-0046 整理フェーズ ③b のレビューの指摘への対応

- 日付：2026-11-24
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F49](../features/ui-cleanup.md#f49-拡大表示の統一と上のバーの切り替え)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-24「整理フェーズ ③b の、利用者の決定（動く見本で、1…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。整理フェーズ ③b の独立レビューの指摘への対応。0.29.0）

- **(1) ページを移ったら、`lightboxBack` を捨てる**：重ねて開いた添付を見ている間に別のページへ移ると、Esc で、前のページの拡大表示（ドックつき）が、新しいページの上に戻っていた（ページを移ったら閉じる判定は、`FocusLayout` が画面にある間しか働かず、`lightboxBack` は、ページを移っても残った）。**`App.tsx` の `useNavigationEffects` で、トピック・ページが変わったときに捨てる**：ドックつきの拡大表示が、ページ移動で閉じる挙動と、同じ結果になる（別のページの上に、前のページのブロックのドックを出さない）。
- **(2) v1 の「通常」は、何もしない**：v1 には、「変更を重ねる」の入口がない。以前は、v1 に切り替えの入口がなかったので、v1 で「通常」を押す操作はなかった。切り替えを、版が 2 つ以上のページで、出すようにしたことで、v1 で押される「通常」が、「変更を重ねる」の設定を、黙って切っていた。`mode === 'normal'` のときの「通常」は、何もしない。
- **(3) 「コメントは、最新版の本文で付けます」に直した**：「通常表示で」と書くと、新しい「通常」ボタンを選んだときだけ付けられるように読める。実際は、「変更を重ねる」の表示でも、コメントできる（比べる画面でだけ、付けられない）。経緯の表（上の、比べる画面の設計の判断）の、当時の言葉は、そのまま（[検証記録](../verification.md)）
