# ADR-0030 版を並べて比べる（F44）の設計

- 日付：2026-11-24
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F44](../features/versions.md#f44-版を並べて比べる)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-23「一旦全ての依頼の実装を全て進めてほしい。明日朝あたり…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。上の依頼の範囲。0.25.0）**版を並べて比べる（F44）の設計**：

- (1) **ブロックごとの行に並べ、左右の欄を、同じ行に入れた**（2 つの縦のスクロールを同期する案は、採らなかった）：スクロールの同期が要らず、高さが違っても、左右が、ずれない。
- (2) **対応づけは、F11 の `matchBlocks` を使う**（比べ方を、2 通り作らない）。**行は、右の本文の順**・**削除は、前の版で次にあったブロックの直前**（同じ場所では「削除 → 追加」。差分で読み慣れた順）。
- (3) **札は文字**（追加・変更前・変更後・削除。色だけにしない）。**文字の差分は、折りたたみで、開いたときに計算する**（変更のブロックが多くても、重くしない）。
- (4) **同じ版を左右に選んでもよく、左を新しい版にしてもよい**（制限しない：「左から右への変更」を強調するだけ）。
- (5) **既定の組は、右＝いま見ている版・左＝その 1 つ前**（v1 を見ているときは、左 v1・右 v2）。
- (6) **読み取り専用にした**：コメントは、最新版の通常表示で付ける（過去の版には、もともと付けられない：F11）。**比べている間は、右のコメント欄を隠し、通常の本文は外す**（番号の層・入口の重ね・コメントの重なりを、出さない）。**開くとき、コメントの入力欄の対象とスレッドの選択だけ閉じ、書きかけの文は残す**。
- (7) **`html-app` の枠は、本文と同じ経路・同じ隔離**（`fillApps` の `compare`。新しい経路を、作らない）。**幅・外観は、比較用のツールバーで、左右そろえる**（レビューの用途が、同じ幅・同じ外観での、位置・ボタンの比較のため）。**枠の中の状態は、共有しない**：同じ操作を、左右に反映するには、枠の中を覗く・操作を中継する通信が要り、N3 の例外を広げるため。上に、一文で、明示した。**左右の幅・外観の覚えは、本文の枠の覚えと混ぜない**（比べる画面を閉じたあとの、本文の枠を、変えない）。
- (8) **状態は `ui.compare` だけが持ち、URL のハッシュには持たない**（版のルートは「見ている版」で、比較は、その上の一時の画面。再読み込みで閉じる）。**ページ・トピックを移ると閉じ、同じページの版の切り替えでは閉じない**。
- (9) **新しい版が届いても、枠を作り直さない**（枠の中の状態が、消えるため）。「右を vN にする」の案内だけ出す。
- (10) **Esc は、枠の外では `escapeStep` の 1 項目・枠の中では、橋の `esc` の知らせを、比べる画面にも渡す**。**枠のコードが、偽の `esc` を送ると、比べる画面が閉じる**（データには触れない。個別表示と同じ：許容）。
- (11) **狭い窓（760px 未満、または欄が 520px 未満）は、左右を上下に並べる**（空白の欄は隠し、札で、どちらの版か示す）。
- (12) **版が 1 つのページのボタンは、`aria-disabled` ＋ `title` ＋トースト**（消さない：なぜ、比べられないのかを、伝える）。
- (13) **サーバー・API・データの形は、変えない**（`usePage` だけ）。
- (14) **返信（カード）の中の枠は、作らない**（N3 の判断が先：§7）。
- (15) **クラス名は `.cmp-sr`**（ビルドの CSS の検査が、`.sr-only` を禁じているため）（[検証記録](../verification.md)）
