# ADR-0064 インライン SVG を、本文の横幅に応じて伸縮させる：`viewBox` の補完と、範囲の画像の修正

- 日付：2026-11-27
- 種別：AI の設計の判断（0.1.8）
- 関連の機能：[F59](../features/doc-format.md#f59-インライン-svg-は本文の幅に応じて縮む)・[F37](../features/zoom.md#f37-本文の画像と図を拡大表示できる)・[F25](../features/region-element.md#f25-本文の好きな範囲を選んでコメントできる)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-27：「SVG も使えるよね？拡大して範囲選択できるの？」→ 見本で検証〔6 種類の SVG：拡大・範囲・複製の id・落とすもの〕・14 個のサンプル集・Mermaid・draw.io との比較の見本 →「インライン SVG（Markdown に直接書いた `<svg>`）も、Mermaid・draw.io と同じように本文の横幅に応じて伸縮するようにして欲しい」）。
- 一覧：[ADR の一覧](README.md)

## 決めたこと

### CSS：直接の子だけを縮める

- 対象は、`:is(#article, .cmpcell.md, .msg .body.md) > svg` と `> p > svg`（`app.css`・2 行）。指定は `max-width: 100%; height: auto`。`.cmpcell.md` は並べて比べる画面の列・`.msg .body.md` は返信の本体。
- **直接の子（と `<p>` の子）だけ**に限り、KaTeX・html-app・UI アイコン・拡大表示のステージ・範囲選択のオーバーレイを巻き込まない。**元の大きさ**：`width` 属性の値を上限にするので、広げない（小さい SVG は拡大しない）。

### `viewBox` の補完

- `viewBox` がなく、`width`・`height` が、どちらも px の数のブロック `<svg>` に、`viewBox="0 0 幅 高さ"` を足す（`markdown.ts`。**無害化のあと、検査した数だけから作る**ので、`PURIFY`・CSP は変えない）。足さないと、枠だけが縮んで図形は縮まず、はみ出した部分が切れる。
- `viewBox` のみ・`width="100%"`・`width="100%" height="200"` は、変化なし。`width` だけ（`viewBox` なし）は、補完しない（幅だけ縮み、高さは変わらず、図形は切れる）。

### 拡大表示は、縮んだ大きさを使わない

- 拡大表示の `svgNaturalSize` は、複製の属性（`viewBox` → `width`・`height`）を読むので、本文で縮んだ大きさは使わない（窓幅 760・列 420px で開いて、1200×800 のまま）。

### 範囲コメントの画像の修正（想定外の不具合）

- **元からあった不具合**：範囲コメントの画像で、ブロックそのものが `<svg>` のとき、範囲の位置に関係なく、図の左上が写っていた（SVG の見本の検証で、AI に届く添付画像が誤る不具合として見つかった）。`region.ts` で、位置指定を SVG にも効かせ、`max-width`・`max-height: none` を足した。
- 以前の不具合（列より広い SVG は、はみ出た部分を本文で選べない）は、解消した。

## 既知の点（残る課題）

- `<div>`・`<figure>` に包んだ SVG は縮まない。`width` だけで `viewBox` のない SVG は、枠が縮んで図形が切れる。
- **SVG の中に `<a href="https://…">` を書くと、資料の本文全体が「本文を表示できませんでした」になる**（コードの不具合の可能性・未修正）。
- SVG の中の `<filter>`・`<use>`・`<style>`・`<script>`・`<foreignObject>`・`<animate>` は、無害化で消える（`filter` を付けた図形は、見えなくなる）。
- 並べて比べるで、v1 と v2 が同じ `id` を違う内容で定義していると、右の図が左の定義で描かれる。
- 拡大表示を Esc で閉じても、元の SVG にフォーカスが戻らない。外部の `<image href>` は、壊れた画像の印が出る（通信は CSP で遮断）。
- インライン SVG は、差分で、箱の位置や線の変更が出ない（文字だけ）。実際のマウス・他のブラウザは、未確認。
