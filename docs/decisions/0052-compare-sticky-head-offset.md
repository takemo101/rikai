# ADR-0052 並べて比べる画面の版の見出しの固定位置を、容器の余白の分だけ負にして、変数で共有した

- 日付：2026-11-24
- 種別：AI の設計の判断（不具合の修正。RIK-067。0.30.2）
- 関連の機能：[F44](../features/versions.md#f44-版を並べて比べる)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-24「（利用者の報告。F44。0.30.2）比較した時のバージョンのヘッダーの位置がおかしい」）。
- 一覧：[ADR の一覧](README.md)

## 不具合

並べて比べる画面の版の見出し（`.cmphead`：「左の版 [v1] 過去の版」「右の版 [v2] 過去の版」）が、スクロールしたとき、画面の上端（上のバー `#docbar` の下）でなく、本文の途中に止まり、その上に本文の行が見えた。

## 原因

- スクロールの容器は `#docscroll` で、`#docbar` はその外にある。`#docscroll` の上端は y=84（`#docbar` の下端と一致）。
- `#docscroll` には、上の余白（`padding-top`）が、広い窓で 32px・900px 以下で 20px ある。
- `position: sticky; top: 0` は、**容器の内容の領域（余白の内側）の上端**に止まる。そのため、見出しは、容器の上端でなく、余白の下（y=116。900px 以下は 104）に止まり、上の 32px（20px）の隙間に、本文の行が通って見えた（見出しの直上の要素は、`.cmpcell`・`LI.blk` などの本文の行）。

## 回帰ではなく、導入時からの不具合

- 二分探索で、`436686f`（0.25.0・F44）・`9617560`・`347d161`・`697451e`（0.28.0）・`8298ed2`（0.29.0）・`49ce742`（整理フェーズ ④c）の 6 点を測り、**すべて同じ値**（広い窓で隙間 32px・900px 以下で 20px）だった。
- `#docscroll` の余白は 0.16.0 から・`.cmphead` の sticky は F44 から。**両方が揃った時点から、あった不具合**。
- 疑った (a) 0.29.0 の `#docbar` の変更・(b) 0.28.0 の折り返し・`hidden`・(c) 整理フェーズ ④c の CSS の順序は、**いずれも原因ではなかった**。

## 決めたこと

- **`.cmphead` の `top` を、容器の余白の分だけ負にする**：`top: calc(var(--doc-pad-t) * -1)`（`compare/compare.css`）。
- **余白の値は、CSS 変数 `--doc-pad-t` で共有する**：`#docscroll` に、`--doc-pad-t: 32px`（900px 以下は `20px`）を定義し、`padding-top` も、この変数にした（`styles/app.css`）。**余白を変えても、見出しの位置は追従する**。
- `#docbar` は容器の外なので、**高さが変わっても（折り返しなど）、追従する**（見出しは、容器の上端に止まる）。
- 1 カラムの狭い窓（〜759px）は、`position: static` のままで、変わらない。

## 採らなかった案

- **`top: -32px` と直書きする**：余白を変えたとき（900px 以下の 20px を含む）に、ずれる。変数で共有すれば、片方だけ直し忘れない。
- **`#docscroll` の `padding-top` を 0 にして、本文の側に余白を持たせる**：本文の最初の位置・番号の層・スクロールの復元など、本文の位置に関わる計算に、広く影響する。見出しだけの直しには、大きすぎる。
- **JS で位置を測って合わせる**：CSS だけで済む。

## 確認（担当の報告）

- 実測 Before/After（スクロール 700）：1360・1100px（最新・過去）：隙間 32px → 0px・直上の要素は `.cmpcell`（本文の行）→ `#docbar`。900・760px：20px → 0px・`LI.blk`／`.cmpcell` → `#docbar`。修正後は、全条件で、`#docbar` の下端と見出しの上端が y=84 で一致した。
- 回帰テスト：`e2e/compare.spec.ts` に 8 件。壊して確認：修正前の `top: 0` では、sticky の 7 件が失敗し、`position: static` の 1 件だけが通る。`top` を `calc(var(--doc-pad-t) * -1 + 3px)` に変えても、7 件が失敗した。
