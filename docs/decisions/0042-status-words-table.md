# ADR-0042 状態の言葉の表

- 日付：2026-11-24
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F48](../features/ui-cleanup.md#f48-名前と状態の言葉と上のバーの整理)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-24「整理フェーズ ③a の、利用者の決定（整理分析の結果…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。上の決定の範囲。0.28.0。整理フェーズ ③a）

- **(1) 状態の言葉の表**：同じ状態を、上のバー・左の行・カードの札・`document.title`・右のタブで、同じ言葉にした（F48 の表）。旧「待ち」「AIの確認待ち」「回答待ち」「進行中」「回答を送信済み」は、別々の言葉で、同じ状態を指していたり、似た言葉で別の状態を指していたりしたため。「AI」と「の」の間は、空白ありに統一。
- **(2) 「追加」「回答を保存」を残し、手がかりを足した**：「AI に送る」に統一すると、「追加」が、送る操作に見える。**追加ボタンの絵を、紙飛行機から「＋」に変えた**：紙飛行機は、「AI に送る」の絵で、「追加」にも付いていると、押すと AI に届くと誤解されるため。入力欄に、「まだ AI には送られません」の注記を 1 行足した。
- **(3) 右のパネルの既定を、1100px 以下で 280 にした**：左の一覧を隠しても、右が 380 のままだと、1100px で本文が 490px にとどまる（左を隠すだけでは、本文が広がらない）。280 にすると、820px。**取っ手で変えた幅は、そのまま**（利用者の操作を、優先する）。
- **(4) 上の札を、「未送信を除く」にした**：未送信は、「AI に送る（n）」の数と輪が言うので、札で重ねて言うと、同じことを 2 か所で言う。「あなたの番」の札は、AI の返信・質問が来たという、別の知らせなので、残した（F39）。
- **(5) 「Claude Code 以外は『rikai に送りました』と伝えてください」は、変えなかった**：エージェントに、伝える文で、画面の言葉ではないため。
- **(6) 識別子・データ・API は、改名しなかった**：画面の言葉だけを直す（改名は、`.rikai/` のデータ・API・コマンドに波及する）。対応表は、`architecture.md`。
- **(7) 420px は、対象外のまま**：半画面（720〜1100px）を使う前提のため。SPEC に明記した（F23）（[検証記録](../verification.md)）
