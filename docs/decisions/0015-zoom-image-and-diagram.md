# ADR-0015 本文の画像・図の拡大の方式

- 日付：2026-11-23
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F37](../features/zoom.md#f37-本文の画像と図を拡大表示できる)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-23「本文の画像要素を、クリックしたら拡大表示されるように…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。上の依頼の範囲。0.18.0）**本文の画像・図の拡大**（F37）：**図は、押された SVG を、複製して〔`cloneNode(true)`・`id` を付け替え〕ライトボックスに出す**（「移す」案は、`#article` の高さ・番号・線・位置づけが崩れるので、採らなかった。同じ `id` が 2 つあると、`url(#…)` が元を指すので、複製の `id` は、接頭辞 `zoom-` で、重ならない形にする。HTML は、文字列から作らず、`innerHTML` を使わない）。**ライトボックスを、添付画像と共通にした**（添付は、これまでどおり、押すと閉じる）。**コメントの付いた画像・図は、押すと、そのコメントを選ぶ**（従来を優先）：**拡大は、入口のバーの「拡大」ボタンから**（コメントの有無に関係なく）。**開かない条件**：文字を選ぶ操作・4px を超えたドラッグ・選択範囲がある状態・範囲を選んでいる最中・修飾キー・右ボタン（文字の選択・コメントの操作を、邪魔しないため）。ズームは 800% まで。**依存は、増やしていない**。**F1〜F36 の振る舞い・HTTP・データの形式・安全（N1〜N3）は、変えない**。既存のテストの、意図した変更：`images.test` の「返信の画像は拡大しない」→「押すと拡大して開く」（[検証記録](../verification.md)）
