# ADR-0063 アラート（注意書き）とタスクリストは、`input` を許可せず、題を DOM に入れずに描く

- 日付：2026-11-26
- 種別：AI の設計の判断（0.1.8）
- 関連の機能：[F58](../features/doc-format.md#f58-資料に注意書きとタスクリストを書ける)・[F11](../features/versions.md)・[F26](../features/doc-format.md#f26-コードブロックの種類で形式を書ける)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-26：他に対応した方がよい描画の候補を示したうえで「以下も対応してほしい：アラート（注意書き）・タスクリスト」→ 見本で「いい感じです」）。
- 一覧：[ADR の一覧](README.md)

## 決めたこと

### アラート：GitHub の記法で、認識は狭く

- 記法：`> [!NOTE]`・`TIP`・`IMPORTANT`・`WARNING`・`CAUTION`。**本文の最上位の引用で、最初の行がマーカーだけのもの**を認める。大文字・小文字は問わず、マーカーの行末の空白と `<br>` は許す。**同じ行に文字があるもの・知らない種類・リストや引用の中のものは、ふつうの引用のまま**（文字も変えない）。アラートの中の引用は、ふつうの引用になる（出典：GitHub の公式文書「入れ子にできない」。大文字・小文字と、同じ行の扱いは、検索の要約〔二次情報〕で、公式文書では確認できていない）。
- 理由：迷うものはふつうの引用のままにする（数式の記法判定 [ADR-0062](0062-math-katex.md) と同じ方針）。既存の引用の見た目・ハッシュを変えない。

### 題を、DOM に入れない

- **題とアイコンは、DOM に文字を入れず、CSS の疑似要素で描く**。題は「メモ · Note」のように英語を併記する（GitHub では WARNING が黄色・CAUTION が赤で、日本語の「警告」「注意」だけだと、重さが逆に見えるため）。アイコンは lucide の線を CSS マスクにした（画面の他の部分と同じ流儀。CSP の `img-src data:` の内側）。地は `--surface`・色は題・アイコン・帯だけ（画面の「状態の色は塗らない」方針）。
- **題の文字を、コメントに入れない**：マーカーの行を DOM から外すので、題は `textContent` に入らず、引用・`blockText`・ハッシュ・`textIndex` の対象外（html-app の `.cap` と同じ考え：[ADR-0060](0060-hide-region-boxes.md)）。カードの見出し（`label`）だけ、「警告: …」のように種類を出す（位置づけには使われない）。

### 差分：種類・チェックの状態は、`sigTag` に入れる

- アラートの種類とチェックの状態は、ブロックのハッシュではなく、`sigTag`（版の対応づけ用）に入れた。差分のメモは「注意書き（警告）→ 注意書き（注意）」「箇条書き・チェック ☐ → 箇条書き・チェック ☑」と出る。入れ子のチェックが変わっても、親の項目が変更になる。

### タスクリスト：`input` を許可しない

- `- [ ]`・`- [x]`・`- [X]`（番号付き・入れ子・段落つきの項目。完了と未完了の混在）。
- **`PURIFY` は、一切変えない**。marked の `checkbox` の出力を `<span class="task-box" role="checkbox" aria-checked aria-disabled aria-label>` に置き換え、**`input` を作らない**（`name`・`form` で、送信に使える入口もできない）。先頭にない偽の印や、AI が HTML に直書きした `data-alert` と `<input>` は、消えるか落ちる。
- チェック欄は、押せない（`pointer-events: none`。クリックは項目に届き、文を選んでコメントする操作を妨げない）。**状態を変えるには、資料を直して新しい版を出す**。完了の項目は、文字を薄くした（`--muted`。取り消し線は付けない）。

## 既存コメントへの影響

- 普通の引用・リスト・番号つきリスト・タスク項目の `blockHash`・`blockId` は、変わらない（タスク項目は、以前から `- a` と同じハッシュだった）。**変わるのは、`> [!NOTE]` で始まる引用のハッシュだけ**（例：`133qr4o` → `167v8sp`）。そのブロックのコメントは、同じ種類で内容が近いブロックとして、推定で見つかる（単体で確認）。ただし、**マーカーを選んで付けた文のコメントは外れる**。

## 既知の点（残る課題）

- 「並べて比べる」画面は、無改造で `sigTag`・`tagLabel` を共有しているので、同じメモが出るはずだが、その e2e はない。
- 同じ行の `[!NOTE] 本文` を、GitHub が普通の引用にする点は、公式文書で確認できていない。
- 本物のスクリーンリーダーでの読み上げは、未確認。
