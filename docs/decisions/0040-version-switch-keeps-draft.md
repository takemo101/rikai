# ADR-0040 版の切り替えで、書きかけのコメントを閉じない

- 日付：2026-11-24
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F11](../features/versions.md#f11-資料は版で残る)・[F39](../features/turn-notify.md#f39-いま誰の番かが一目で分かる)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-24「整理分析（/tmp/analysis/）の結果への、…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。上の決定の範囲。0.27.1。整理フェーズ 0）**版の切り替えで、書きかけのコメントを、黙って閉じないことにした**（実際の Chrome で、書きかけの文が、消えるのを再現した：UX 分析 P1）：**F44 の「対象を失った下書き」の仕組みに揃えた**（別の持ち方を、作らない）。**最新版へ**（新しい版が届いた）：入力欄と文を残し、`verify` で、対象が新しい本文に見つかるかを、描いたあとに確かめる（見つかれば続け、見つからなければ、下書きへ）：F44 の、同じページの最新版のときと、同じ扱い。**過去の版へ**（版の選択）：**書きかけを、「対象を失った下書き」へ移した**：コメントは、最新版にしか付けられない（F11）。過去の版では、入力欄の対象を、本文に出せず、入力欄を開いたままにすると、**対象のない入力欄**になるため。文は、消さず、利用者が、コピー・破棄を選べる（理由「過去の版にあります」・トーストで知らせる）。**別のページ・トピックへ移るとき**も、同じ（対象を戻せない。トピックを移るときは、添付の画像〔そのトピックの `assets/`〕は、持ち越さない）。**`.omc/` を、追跡から外した**：個人のパスを含む、ツールのメモで、リポジトリに入れない（コミットしない：`development.md` の規則）。内容は、リポジトリの外に退避した。**`app/e2e/env.ts` の、個人のパスの既定を、削除した**：`RIKAI_CHROME` → 一般的な場所 → `PATH` → なければ skip（ブラウザは、ダウンロードしない）。**`SKILL.md` を、実装に合わせた**（`rikai` が PATH にないこと・`rikai.state` が `frameMeta.state` に入ること・`poll` の出力の形ほか）：AI が、古い記述に、従わないように（[検証記録](../verification.md)）
