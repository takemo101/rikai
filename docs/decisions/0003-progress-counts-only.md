# ADR-0003 理解の進み具合は、数だけを見せる

- 日付：2026-11-21
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F21](../features/threads.md#f21-理解の進み具合を数で見られる)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-21「進められるものは、タスクに分けて、PR ごとに me…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。上の委任の範囲）理解の進み具合は、数だけ（解決したスレッド・送信済みの回答がある質問）を見せる。「正解」の数と、「理解できた」という判定は、しない（正解は、AI が返信の文章で採点するもので、構造のデータにない）
