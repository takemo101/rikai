# ADR-0023 範囲選択の画像で、枠を「枠の箱」に置き換えた

- 日付：2026-11-23
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F25](../features/region-element.md#f25-本文の好きな範囲を選んでコメントできる)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-23「html の中の要素を範囲選択すると、真っ黒な画像に…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。上の報告の範囲。0.22.1）**範囲選択の画像で、html-app の枠を「枠の箱」に置き換えた**（F25）：枠は、別オリジンの隔離した iframe で、複製に中身が入らず、背景だけが写って、真っ黒になっていた。**複製の iframe を外し、同じ位置・大きさ（`getBoundingClientRect`。縮小表示の `transform` も含む）に、点線の枠・地と区別できる背景・中央に「実行できる枠（画像にできません）」の箱を置く**。文字・枠線の色は、画像の地の明るさで決める。箱は、複製の外に置く（祖先の `transform`・`overflow` に左右されない）。**隔離〔`sandbox`・`APP_CSP`〕は、緩めない**（枠の中を、親から読まない）。箱は「枠がある」ことを示すだけで、中身は写らない（本当の直し方は、段階 2：§7）。枠のない範囲は、変えない。サーバー・CLI・HTTP・データの形式は、変えない（[検証記録](../verification.md)）
