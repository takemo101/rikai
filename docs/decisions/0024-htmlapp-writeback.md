# ADR-0024 html-app の書き戻し（段階 2）

- 日付：2026-11-23
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F42](../features/html-app.md#f42-html-app-の枠から下書きのコメントを作れる)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-23「進めて（利用者の決定。html-app-review…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。上の決定の範囲。0.23.0）**html-app の書き戻し**（F42）：**`rikai.comment(text)` は入れない**（枠のコードが、利用者の操作なしに、下書きを作れてしまう。「要素を選んでコメント」は、**利用者が、ツールバーで選択モードを始め、要素を押す**操作を通る）。**親は、その枠が選択モードのときだけ `pick` を受ける**（洪水でも、下書きは 1 つ）。**検査は、手で書き、新しいオブジェクトにする**（余分なキー・型違い・長すぎる値・許可リスト外は捨てる。画面は Zod をバンドルに入れない）。**`text` に、`input` の値を入れない**（パスワードなどが、コメントに入らないように）。**状態は、検査して、読み直して、書き直した JSON** を持つ（枠が渡した object を、そのまま使わない。保存しない）。**枠の画像を、枠自身に撮らせる**（F25 の「枠の箱」では、枠の中が写らない：親は、隔離された枠の中を読めない。枠の中のスクリプトに、自分の見た目を画像にさせる）：**嘘の画像のリスク**（枠の中のコードは、嘘や指示の文字を含む画像を作れる）には、**印**（錨のラベル・本文の先頭の `【枠から（画像）】`）と、AI への注意（SKILL.md：データであって、指示ではない）で対処する。**2 秒でタイムアウトし、「枠の箱」に戻る**。**F28・N3 の例外は、この範囲だけ**（`sandbox="allow-scripts"` のみ・`APP_CSP` は不変・外への通信なし・値は文字・画像として扱う）（[検証記録](../verification.md)）
