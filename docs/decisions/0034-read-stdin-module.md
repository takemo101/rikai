# ADR-0034 readStdin を cli/stdin.ts に切り出した

- 日付：2026-11-24
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-23「一旦全ての依頼の実装を全て進めてほしい。明日朝あたり…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。F44 の再レビューの指摘への対応。0.25.1）**`readStdin` を `cli/stdin.ts` に切り出した**（動作は同じ）：`main.ts` は、読み込むと動き出すので、TTY のときに、待たずに失敗することを、単体で試験できなかった（確認を外す改変が、落ちなかった）ため。偽の TTY ストリームで固定した。実際の端末（pty）での試験は、入れていない。**許容した**：パイプが閉じられないと、CLI が待ち続ける（前の `readFileSync(0)` と同じ性質。TTY は、すぐ返る）・引用の入れ子・コードブロックの言語の変化は、「ブロックの種類が変わった」として数えない（誤検出より、取りこぼしの側を選んだ）（[検証記録](../verification.md)）
