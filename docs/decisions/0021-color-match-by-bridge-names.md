# ADR-0021 配色の対応の判定を、橋が配る名前に絞った

- 日付：2026-11-23
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F40](../features/html-app.md#f40-html-app-の枠と画面をつなぐ橋)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-23「html を強化していく。デザインの比較・UI のレ…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。再レビュー〔2 回目〕の指摘への対応。F40）**配色の対応の判定を、橋が配る名前に絞った**：`var(--color-<橋の名前>` を使い、かつ、同じ名前を自分では定義していない枠・`<meta name="color-scheme">` を書いた枠だけ。`data-theme` の包含はやめた。**理由：自作の `--color-*`（`--color-primary`・`--color-bg`・`--color-text` など）を書いた従来の資料を、壊さないため**（`var(--color-` を含むだけで true にすると、土台が付いて、ダークで、背景だけが残り、文字が白くなった：AI がよく書く形）。**`100vh` の止め方**：超える分が 64px 以下で、高さが 2400px 以下のときだけ `overflow-y: hidden`・それ以外は `auto`（`100vh` のヒーローの下に、本物の節が続く資料の中身を、隠さないため）。**縮小表示の縮小率の下限を 50% にした**（1920px を 33% や 7% にすると、読めないため）。収まらない幅は、横にスクロールして見る（3 層の構造：`.appview` > `.appscale` > iframe）（[検証記録](../verification.md)）
