# ADR-0051 「Markdown を保存」を、常にアイコンだけにした

- 日付：2026-11-24
- 種別：AI の設計の判断（0.30.1）
- 関連の機能：[F50](../features/versions.md#f50-markdown-を保存)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-24「（利用者の要望。F50。0.30.1）ダウンロードできたのですが、他との統一感を出すために、アイコンだけの方がいいかもしれません」）。
- 一覧：[ADR の一覧](README.md)・[ADR-0050](0050-save-markdown.md)（0.30.0 の仕様と設計。このADRは、その (3) の「560px 以下だけアイコンにする」を、変えた）

## 決めたこと

- **ボタンは、常にアイコンだけ**にした（どの幅でも）。見た目は、上のバーのほかのアイコンのボタン（ベル・外観・☰）と同じ **`iconbtn`**（26px 角・枠なし・同じフォーカスの輪）。ラベルの文字（`.save-t`）は、なくした。
- **名前は、`aria-label="Markdown を保存"`（読み上げ）と `title`（ホバー）で持つ**。`title` は「Markdown を保存：このページの、いま見ている版（vN）を、<ファイル名> として保存します（コメントは含みません）」（ホバーの先頭が名前）。読み込み中・取得失敗の `title` は、従来のまま。
- **上のバーのアイコンのボタン（☰・保存・ベル・外観）は、縮めない**（`#top > button.iconbtn, #btn-side { flex: none; }`）。先に縮むのは、題と状態の札。
- **560px 以下は、上のバーの余白を詰める**（`#top { gap: 4px; padding: 0 4px; }`。0.30.0 は `gap: 6px; padding: 0 6px`）。

## 理由

- 利用者の要望：上のバーのほかのボタンとの統一感。0.30.0 は、560px より広いときだけラベルつきで、見た目が、ほかのアイコンと揃わなかった。
- アイコンだけにすると、560px 以下の個別の規則（`.save-t` を隠す・ボタンを 26px にする）は、要らなくなる。

## 当初の見込みと、戻せなかった理由

- 当初は、「アイコンだけなら、560px 以下の余白詰め（0.30.0 で足したもの）も、要らなくなる」と見込んだ。**完全には戻せなかった**。
- 余白詰めなしだと、上のバーのアイコン 4 つ（☰・保存・ベル・外観）が、「AI の返信待ち」の札やヒントと一緒に縮む。**この縮みは、以前からあった**（1100px で 20px・600px 以下で 15px）：保存のボタンを足す前から、ベル・外観・☰ は縮んでいた（気づきにくかった）。縮むと、アイコンの大きさが、ボタンごとに揃わない。
- そこで、アイコンを `flex: none` で縮めないようにした。代わりに、560px 以下の余白を詰めた（`gap: 4px; padding: 0 4px`）。**詰めないと、420px で状態の札が「AI に送る」に重なり、360px でバーがはみ出す**。

## 副作用（意図したもの）

- **上のバーのアイコン（☰・ベル・外観）も、これからは縮まなくなる**。狭い窓で、先に縮むのは、題と状態の札になる。以前の「アイコンが 15〜20px まで縮む」より、アイコンが押しやすい。

## 採らなかった案

- **560px 以下の余白詰めを、元に戻す**：上のとおり、アイコンが縮む（大きさが揃わない）。
- **保存のボタンだけ、`flex: none` にする**（0.30.0 の方式）：保存だけが 26px で、ほかが縮むと、大きさが揃わない。
- **ラベルを、狭い窓だけでなく、広い窓でも残す**：利用者の要望（統一感）に反する。

## 確認（担当の報告）

- 実測：1360・1100・900・760・600・560・420・360px で、保存・ベル・外観は 26px のまま・バーは 1 行（高さ不変）・はみ出し・重なり 0・「AI に送る」「終了」が全部見える。既存の 420px 系の e2e（`turn`・`frame-meta`・`focus`）も通った。
- 壊して確認：`aria-label` を外すと、単体（1 件）と e2e（2 件）が落ちた。
