# ADR-0012 同じ行の複数のコメントの見せ方

- 日付：2026-11-23
- 種別：AI の設計の判断（もとは、SPEC.md の §8 の表の 1 行。文言は、そのまま移した）
- 関連の機能：[F22](../features/appearance.md#f22-コメントと本文の位置が分かる)・[F35](../features/appearance.md#f35-コメントと本文の対象を線で結ぶ)
- 決定の元：[利用者の決定](user-decisions.md)（2026-11-23「同じ行に別々のコメントがあった場合の表示は？→改善で…」）。文中の「上の…」は、この決定を指す。
- 一覧：[ADR の一覧](README.md)・[SPEC.md の §8](../../SPEC.md#8-利用者の判断)

（AI の判断。上の依頼の範囲。0.16.1）**同じ行の複数のコメント**（F35 の (6)。F22 の丸は、要件を変えず、参照する）：**丸**は、折り返さず、右詰めで、2px ずつ重ねて並べる。幅は、文字数で決め、`width` で固定する（1〜4 文字で 18／24／31／38px）。**左の見える幅に収まる数だけ**並べ、**6 件以上は、先頭 4 つと「+N」**（1 つも収まらなければ「+N」だけ）。「+N」は、ホバーで、まとめた丸を、実際の大きさのポップオーバーに開く（「+N」の真下。下に入りきらなければ、行の上）。記事の左の余白は、広い窓（901px 以上）で 36px（狭い窓は 8px のまま）。**線**は、すべて、同じ x（記事の右端 +6px）まで水平に引き出してから S 字に入る。引き出しの高さは、強調の矩形の下端 + 2px（行間）・同じ行は、カードの高さの順に、行間の中で 2px ずつずらす（同じ行も、隣の行も、交差しない）・引き出しの部分は、別の線で、薄い点線・1 件だけの行は、強調の右端の中央から出す。**レビュー（2 回）による仕様の調整**（丸の幅・ポップオーバーの置き場・引き出しの高さと見た目・1 件だけの行の始点）。**「5 つまで並べる」は、実装者の解釈**：利用者の最初の指定は「4 個まで・5 個目から +N」だが、**ちょうど 5 件のときに、「+1」にまとめるより、5 つ並べる方が、一覧できる**ので、5 つ並ぶ幅があれば、5 件ちょうどは、並べる（6 件以上で、先頭 4 つと「+N」）。**この解釈は、利用者が確認済み**（2026-11-23。下の「利用者の回答」の行）。**ボタン名の変更（意図した違い）**：「理解できた（解決）」→「**解決**」・「返信を追加」→「**追加**」（返信の入力欄のボタン。「コメントを追加」は、そのまま）。アクセシブルな名前も同じ。`title` は「理解できたら、解決にします」「返信を追加します（⌘/Ctrl＋Enter）」。**振る舞い・HTTP・データの形式・安全・縁の扱いは、変えない**。上の 2026-11-23 の行の「「返信を追加」と同じ行」は、当時の名前（[検証記録](../verification.md)）
